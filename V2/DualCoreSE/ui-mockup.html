Added in v1.3.0

  • Wi-Fi clock. NTP from loop(), never from a UI event: the same wifi.txt as LauncherOS, single +30 min UTC steps, auto top-up every six hours, radio dropped when done.
  • One accent, three OSes. Champagne, ice, mint, violet, crimson or platinum — or OS DEFAULT, which restores each palette.
  • NoirOS wallpaper. 410×502 RGB565 frames from /WATCH/PHOTOS in PSRAM, with a scrim so the clock stays readable.
  • Developer info. Heap, PSRAM, SD, reset and wake reason, uptime, boot strikes and wallpaper state on one screen.
  • Factory reset. Per experience, or all three — always confirmed, never automatic, and the chooser stays reachable.

Added in v1.2.0

  • Sovereign face. A fluted bezel, champagne sunburst dial, day aperture and cyclops date — with a digital heart. Original marks only.
  • Deep sleep + light sleep. Panel-off light sleep like LauncherOS; optional idle deep sleep that wakes on BOOT or the next alarm, then reopens the last experience.
  • Alarm weekdays. Each of the three alarms gets a day mask, with at least one day always kept.
  • Weather from the phone. Temp, condition and high/low with a clean “no data” state instead of invented numbers.
  • Runtime estimate. Derived from the battery poll over a 10-minute window, shown as approximate.
  • Event alerts. Opt-in 15-minute warning that arrives through the shared inbox, so privacy applies.
  • Stealth display. Time-only, dim crimson, tap to return.
  • Red light. The flashlight cycles white → red → off; red really lights only the red subpixels.
Still in: quick sheet, three-event agenda, per-alert dismiss, focus presets, Roman/Moon faces, moon phase, seconds toggle, crimson palette, breathing pacer.

Try this

Press and hold the watch's top bar for about half a second — the quick sheet slides up.
In NoirOS, tap an inbox row, then DISMISS; or use the small X on any row.
Open CrownOS → Studio, pick the LUNE face and watch the moon phase change with the real date.
In NightOS → Shadow, switch the palette to CRIMSON: the whole OS retints, including the utility panel.
In NightOS → Utility, tap FLASHLIGHT twice for the red light, then STEALTH DISPLAY for the time-only screen.
Open the quick sheet and set AUTO SLEEP, then SLEEP NOW to see the wake screen and its alarm timer.

What this is

HTML/CSS/JS, 410 × 502 CSS pixels, no external assets. It mirrors the firmware's layout grid: 58 px top bar, 378 px body, 66 px tab bar, 12 px corner radii, Montserrat-like type scale. Typography and anti-aliasing will differ from LVGL on the watch; the geometry and interaction model will not.

Firmware status: the same feature set compiles for the WOS 206A (21 % flash, 31 % static RAM). Phone link, touch feel and power draw still need the physical watch.
